# GrokBot Cloud MicroVM Scraped Architecture & Assets

Scraped from autonomous cloud agent microVM (`box@cursor:/workspace`).

## Contents
- `exec-daemon/`: Complete `@anysphere/exec-daemon-runtime`, agent SDK, canvas runtime, tools, node modules.
- `usr-local-bin/`: Supervisor scripts (`sand-exit-watch`, `start-desktop.sh`, `box-chrome`, `box-xvfb`, `box-x11vnc`, `box-cgroups.sh`).
- `usr-local-share/`: WebAuthn inverted proxy Chrome extension, CRX, PEM, ID.
- `etc-policies/`: Chrome managed policies (`sand-webauthn.json`, efficiency mode, WebRTC IP leaks).
- `home-box/`: User configs, Plank dock settings, GTK file chooser pre-seeds.
- `system-info/`: Kernel boot arguments, mount layout, installed packages, process tree, port mappings.
